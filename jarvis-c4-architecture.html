C4 · Level 3

Components of jarvis-server

The dispatcher fans nine tools out to four engines; the SCIP decoder stays the only module that ever touches protobuf or zstd.

Load-bearing invariants

Guarantee 01

Read-only runtime

Every query opens published indexes with mode=ro&immutable=1. Many readers coexist, and no query path ever mutates an index file.

Guarantee 02

Atomic publish

A reindex writes versioned artifacts first; only after graph, Zoekt, and semantic stages all succeed does the current pointer flip via os.replace(). No partial state is ever visible.

Guarantee 03

Rebuild, not accumulate

Each run clears the repo's outgoing package edges before recomputing them, so blastRadius never serves stale dependencies.
