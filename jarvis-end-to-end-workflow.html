Process · Diagram Design

Jarvis — from repository to MCP result

The full local lifecycle: git-aware indexing creates versioned SCIP, search, graph, and semantic artifacts; the MCP runtime then reads those published artifacts to answer navigation and search requests.

THE PIVOT

Atomic publish is the safety gate

The new index-<sha>.db becomes visible only when graph and Zoekt work have completed; current is then swapped atomically.

FAILURE SEMANTICS

Old state stays live

  • Unrecognized failures leave the prior pointer untouched
  • Semantic indexing is optional and non-fatal
  • Known indexer failures may publish search-only

WATCH MODE

Changes converge through the same path

watch filters build noise, debounces edits, and triggers the same full reindex workflow without changing the runtime read contract.
