<objective>
Stamp origins on every degradation write and close the pre-pipeline failure gap.

Every search-only publish (manual flag and signature match) records which path produced it and why; failures inside those paths and before the pipeline proper (version gate, language resolution) persist failed_hard rows so no failure mode leaves the registry silent.

Purpose: STAT-01's SC2 — a repo in search-only state via existing paths reports its origin and a recovery command; the taxonomy accepts Phase 3's `degraded` without reshaping (D-01/D-09).
Output: origin-aware `upsert()`, three wired hook points in `index_repo()`, tests proving the persisted origins.
</objective>
