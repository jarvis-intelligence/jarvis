<objective>
Machine-readable degradation reporting at the MCP boundary.

Nav-tool errors on degraded/search-only repos carry `state`/`cause`/`recovery` structured keys (D-14); `getIndexStatus` exposes `last_index_run` (what the last run did) and `capabilities.{navigation,search,semantic}` (what the system can do right now, pointer-truth) so an MCP client branches without parsing prose.

Purpose: STAT-02/STAT-03 (ROADMAP SC3/SC4) — the agent-facing half of "explains why and how to recover"; the payload shapes are the contract Phase 3's degraded state slots into unchanged (D-15).
Output: Extended `server.py` (`_registry_entry`, `_error_payload` keys, `get_index_status` capability fields), tests in `test_server_tools.py`.
</objective>
