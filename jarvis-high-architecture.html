Jarvis — local-first code intelligence

One stdio MCP process exposes structural navigation, lexical search, semantic retrieval, and dependency blast radius while a separate indexing path builds immutable local artifacts.

THE SEAM

Storage is the contract boundary

The runtime opens published SCIP databases read-only with mode=ro&immutable=1; the indexing path creates new versioned artifacts and swaps only the small pointer.

RUNTIME

One local MCP surface

  • FastMCP runs over stdio
  • 9 tools share QueryService, ZoektLifecycle, and GraphStore
  • Search and semantic capabilities degrade best-effort

INDEXING

Build, then publish

jarvis index and watch reuse the same pipeline: git-aware detection, language indexer, conversion, sidecars, and atomic publication.
